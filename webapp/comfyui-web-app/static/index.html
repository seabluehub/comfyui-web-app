新建角色定义

配置人脸骨骼、特征权重、专属 LoRA 与色彩排他屏障，实现 1000 张变体稳定量产。

✨ 一键套用官方工业级示范预设（点击自动填入标准参数）：
界面展示名，支持中英文。
用于文件命名与数据检索，唯一不可重复，仅限英文字母/数字/下划线。
在导航栏与角色卡片中展示的个性化图标。
决定默认生图工作流节点模板。
💡 权重语法说明：强制拼接在所有变体最前面。强烈建议对核心五官使用括号加权，如 (character_face:1.25)，确保跨画风时人脸轮廓不崩坏。
🛡️ 色彩屏障原理：当角色为银发时，必须在负向词中屏蔽 brown hair, black hair，防止穿黑色/棕色服装时头发被环境混色染色。
存放于 models/loras/ 目录下的微调权重，留空则仅使用纯 Prompt 生成。
工业推荐值 0.80 ~ 0.95。低于 0.70 容易被画风吞噬，高于 1.05 画面容易烧焦。
