# 固定角色 1000 张变体工业级量产生图系统 (ComfyUI Web App)

> **基于 ComfyUI API + FastAPI + 原生 SPA 的二次元角色工业化量产调度与成果画廊系统**  
> 支持 1000 变体参数矩阵、四层立体一致性防护、多角色全生命周期管理、柔性分批单队列安全调度、物理温控防降频与全链路工艺参数追溯。

## 一、 业务背景与核心痛点

在动漫游戏、IP 衍生品、虚拟主播与轻小说插画制作中，**“批量生成固定角色的多样化海量立绘”** 是一项高频商业诉求。但在传统 AI 绘画实践中，量产 1000 张变体面临四大严峻的工程与业务挑战：

| 痛点维度 | 现象与业务影响 | 传统方式的局限 |
| :--- | :--- | :--- |
| **1. 角色形变漂移** | 提示词一旦切换画风（如水彩、哥特）或穿上复杂服饰，角色五官崩坏、发色被衣服颜色污染染色、瞳色丢失。 | 纯文生图（Text-to-Image）潜空间随机游走过大，缺乏有效几何锁定。 |
| **2. 1000 级量产不可控** | 1000 张连续全量生成耗时长达数小时到数十小时；并行跑极易引发显存溢出 (OOM)；高负荷导致 GPU 过热降频掉速。 | 缺乏自动化长时调度、单队列防爆保护与断点续跑容错机制。 |
| **3. 缺乏定制分批能力** | 业务往往需要先挑选“赛博朋克+水手服”特定 10 张审焦，无法在 1000 任务中自由组合筛选子集生产。 | 脚本只能从 1 跑到底，调整参数困难，灵活性差。 |
| **4. 工艺参数不可追溯** | 出了一张极佳效果图后，无法精准查证当时使用的是哪个底模、哪款 LoRA 及其权重、何种采样算法与 Seed。 | 缺乏生产配置结构化入库（JSON 元数据追溯），无法高质量复刻。 |

## 二、 业务解决方案

本项目提供了一整套端到端的二次元角色工业化量产业务解决方案：

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        业务解决方案总体架构全景                         │
├─────────────────┬─────────────────┬──────────────────┬──────────────────┤
│ 1. 矩阵展开引擎 │ 2. 立体一致性   │ 3. 柔性分批调度  │ 4. 多角色管理    │
│ 10 画风 ×       │ 四层阶梯防护    │ 标签多选筛选     │ 角色库全属性CRUD │
│ 20 服装 ×       │ 语法加权+色彩屏 │ 单队列防并发     │ 4套工业级预设    │
│ 5 姿态 = 1000组 │ LoRA+FaceDetail │ 温控散热+显存回收│ 1000矩阵自动生成 │
│ 确定性Seed绑定  │ IP-Adapter锚定  │ 优雅暂停/断点续跑│ 任务与画廊物理隔离│
└─────────────────┴─────────────────┴──────────────────┴──────────────────┘
                                   │
                                   ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ 5. 一致性 4 阶段横向对照实验    │ 6. 全生命周期可追溯成果画廊           │
│ 同 Seed / 同姿态单张对照分析    │ gen_config 完整参数入库 (底模/LoRA/步数)│
│ 直观对比 Phase 1 ~ Phase 4 效果 │ 响应式瀑布流 + 多维过滤 + 一键原图下载  │
└─────────────────────────────────────────────────────────────────────────┘
```

### 1. 1000 变体参数笛卡尔矩阵
- 预置 **10 种顶级动漫画风**（吉卜力手绘、新海诚唯美、赛博朋克霓虹、水彩淡彩、洛可可华丽、暗黑哥特、90年代赛璐璐等）；
- 预置 **20 套丰富服饰**（水手制服、振袖和服、机能特工服、英伦风衣、哥特洛丽塔裙、女仆装、旗袍、汉服等）；
- 预置 **5 种戏剧性镜头姿态**（疾驰跃动、微风肖像特写、伫立远眺广角、闲坐憩息、仰视英雄视角）；
- 矩阵生成器自动生成 **1000 组中英文提示词** 与确定性随机 Seed，数据完全入库持久化。

### 2. 四层递进立体一致性防护体系
针对跨画风、跨服装、跨姿态的角色一致性难题，系统支持四层递进式解决方案：
- **Phase 1（基础基准）**：通用文生图，无权重语法，作为基准对照组（一致性评定：`★☆☆☆`）；
- **Phase 2（Prompt 加权与反向色彩屏障）**：核心面部词置于前 15 Token 强制加权 `(name_face:1.25)`，并在专属负向词中加入相斥色彩屏障（如银发角色屏蔽 `brown hair, black hair`，杜绝穿深色服装时被环境混色染色）（一致性评定：`★★☆☆`）；
- **Phase 3（专属 LoRA 几何骨骼锁定）**：挂载角色专用 LoRA（推荐 `0.85` 强度），锁定面部轮廓、眼型比例与发流细节，跨画风保持同一个人（一致性评定：`★★★☆`）；
- **Phase 4（全链路立体防护）**：基准正脸立绘通过 **IP-Adapter / FaceID** 注入跨注意力层 + 角色 LoRA + 远景面部二次局部重绘 (**FaceDetailer**)，实现跨极端异构画风依然稳定（一致性评定：`★★★★`，一致性 >95%）。

### 3. 多角色全生命周期管理
- 完整支持角色的 **创建、查看、编辑、删除**；
- 字段涵盖：中文名称、英文标识代号、头像 Emoji、基模架构（SDXL/Flux）、特征加权触发词、专属负向屏障词、LoRA 文件名与权重、人设背景描述；
- 内置 **4 套官方标准二次元角色预设**（露米娜/星野/艾尔莎/墨羽），配有详尽的字段释义与语法避坑指引，支持一键套用；
- 新建角色支持 **0.2 秒内自动展开该角色的 1000 张变体矩阵**，且多角色之间的数据与画廊完全隔离。

### 4. 柔性分批定制与单队列安全调度
- **结果集多维组合筛选**：画风、服装、姿态支持任意多选，实时计算匹配任务数（Pending / Success / Failed）；
- **单队列防显存碎片安全调度**：坚决不做并发执行，杜绝多任务抢占显存导致 CUDA OOM；
- **物理硬件长时保护**：连续量产 30 张自动休眠 15 秒（辅助笔记本降温防降频），每 50 张调用 ComfyUI `/free` 主动回收 PyTorch 显存碎片；
- **优雅任务控制**：支持随时暂停（Pause）、恢复（Resume）、终止（Stop），崩溃自动将 `RUNNING` 状态回滚为 `PENDING`，支持断点续跑。

### 5. 全生命周期可追溯成果画廊
- 数据库新增 `gen_config` 结构化字段；
- 每张图片详情弹窗完整展示：工作流模板、底模文件名、LoRA 文件及权重、步数、CFG、采样器、调度器与引擎类型（实机 / 仿真）；
- 支持多维标签快速过滤、评分、收藏与一键下载高清大图。

## 四、 快速开始与本地部署指南

### 1. 环境准备
- **操作系统**：Windows 10 / Windows 11 / Linux
- **Python 版本**：Python 3.10 ~ 3.13（推荐 3.10.11）
- **ComfyUI 实例**（可选）：本地 ComfyUI 服务默认运行在 `http://127.0.0.1:8188`

### 2. 安装依赖
```powershell
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 3. 配置环境变量
复制 `.env.example` 为 `.env`：
```ini
# 服务端口
PORT=8080
HOST=0.0.0.0

# 运行模式：
# - false: 连接本地真实 ComfyUI 出图 (需要 127.0.0.1:8188 已启动)
# - true:  仿真测试模式 (无显卡环境体验完整调度与画廊)
MOCK_MODE=false

# ComfyUI 地址
COMFYUI_HOST=127.0.0.1
COMFYUI_PORT=8188

# 硬件温控保护策略
COOLDOWN_BATCH_SIZE=30      # 连续完成 30 张自动冷却休眠
COOLDOWN_SECONDS=15         # 每次休眠 15 秒
FREE_MEMORY_BATCH_SIZE=50   # 连续完成 50 张调用 ComfyUI /free 释放显存
```

### 4. 启动服务
#### 方式 A：一键批处理脚本启动（推荐）
直接双击运行 `start_server.bat`，或在终端执行：
```powershell
.\start_server.ps1
```
启动成功后，在浏览器访问：👉 **`http://localhost:8080`**

#### 方式 B：Python 模块直接运行
```powershell
python -m uvicorn app.main:app --host 0.0.0.0 --port 8080 --reload
```

## 五、 核心功能操作指引

### 1. 多角色管理与示例预设套用
1. 访问首页 `http://localhost:8080`，点击顶部导航栏中的 **“👥 角色管理”**；
2. 在左侧角色列表中可查看已有角色（露米娜、星野等）；点击 **“+ 新建角色”**；
3. 点击表单顶部的 **“✨ 一键套用预设”**（如点击“🪭 墨羽 (古风黑发)”），系统自动填入：
   - 特征触发词：`1girl, (moyu_face:1.25), (sleek straight jet-black hair:1.2), (deep crimson red eyes:1.2), bindi on forehead`；
   - 负向色彩屏蔽词：`blonde hair, silver hair, blue eyes, modern glasses`；
   - 专属 LoRA 与推荐权重：`moyu_hanfu_v1.safetensors`（强度 `0.85`）；
4. 保持勾选 `[√] 保存后立即展开生成 1000 张变体量产矩阵`，点击 **“保存角色设定”**，系统即为该角色建立专属任务池；
5. 在顶栏下拉框即可直接在多个角色之间无缝切换。

### 2. 一致性 4 阶段横向对照实验
1. 点击顶栏 **“🔬 一致性对比”** 按钮打开实验测试室；
2. 选择待测角色、画风、服装与固定 Seed；
3. 点击 **“🚀 开始 4 阶段对比分析”**；
4. 系统将在同一画布横向呈现 4 列对照卡片：
   - **Phase 1**：纯文本基准（易漂移，`★☆☆☆`）；
   - **Phase 2**：提示词加权与色彩反向屏蔽（色彩初步锁定，`★★☆☆`）；
   - **Phase 3**：专属 LoRA 挂载与骨骼锁定（五官几何锁定，`★★★☆`）；
   - **Phase 4**：全链路立体防护（IP-Adapter + LoRA + FaceDetailer）（终极稳定，`★★★★`）。

### 3. 分批量产控制台定制生产
1. 访问 `http://localhost:8080/batch.html`（或从画廊右上角点击 **“🗂 分批量产”**）；
2. **步骤 1（筛选子集）**：在“画风”、“服装”、“姿态”下拉框中勾选目标组合（支持一键全选/反选），右侧即时计算匹配任务数量；
3. **步骤 2（配置大模型）**：选择推荐预设（如“⚡ 极速量产”）或自定义底模、LoRA 权重与步数；
4. **步骤 3（顺序执行）**：点击 **“开始单队列生产”**，实时观察采样步数环、温控状态、实时预览图流与剩余耗时；
5. 过程中支持随时点击 **“⏸ 暂停队列”** 或 **“⏹ 终止生产”**，进度自动保存，随时断点续跑。
